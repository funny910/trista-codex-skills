# 方法库二：动画角色与场景资产

**【通用方法草案 v0.1】** 用于文字规格、参考素材检查和方案比较；不生成图片或视频。按 U04、U05 已确认的规则执行；其余方法与示例仍为通用建议，真实项目效果尚未验证。无需用户一次确认整库。

先读取项目已确认的故事事实、视觉方向与资产版本。原稿未写明的设计可以给候选，但不能作为既定身份；图片中不能确认的背面、尺寸、材质和空间关系保持待核实。

<a id="a01"></a>
## A01 · 角色识别与可变部分

- **解决问题：** 同一角色在不同镜头里难以辨认，或多个角色的视觉特征混淆。
- **适用：** 角色要跨镜头复用，需要建立文字设定或核对已有参考。
- **不适用：** 只有一次简单出镜却无必要地扩展整套人设；用外形推断用户未提供的人格、年龄或背景。
- **操作：** 从原稿与已确认图片提取辨识特征，将稳定身份、服装状态、表情姿态和剧情变体分开。按具体景别检查哪些特征可见；缺少设计时提供少量有区别的候选，并解释识别优势与细节负担。
- **示例：** 假设参考已确认阿禾的外套左袖有补丁，可将补丁作为一个身份锚点；近景核对位置，远景不要求凭这个小细节单独辨认。
- **反例：** 原稿没有服装信息，却把示例中的外套写成用户确认设定；用同一个名字宣称跨镜头身份已经一致。
- **检查：** 身份特征有来源；固定与可变部分清楚；重要景别下的识别需求被考虑。没有实际图时只能检查规格完整性。
- **传递：** 已确认锚点进入 AST 对应版本、相关 SH 及提示词草案；更换服装变体时仅更新引用该变体的产物。
- **【待你确认 U04 / U05】** 你的画风中哪些身份特征最重要，哪些变化可以接受。不得强制统一头身比或固定特征数量。

<a id="a02"></a>
## A02 · 按动作需求准备表演与视角参考

- **解决问题：** 角色图好看，但不足以支持计划中的转身、拿取、行走或细微表演。
- **适用：** 分镜已有明确动作，需要决定是否补视角、姿态、表情或局部参考。
- **不适用：** 每个角色自动要求全套三视图、表情表和动作表；把参考需求等同于已完成的素材。
- **操作：** 按已确认 U05 优先复用现有适用素材，从 SH 反查动作与可见部位，只列必要的视角、表情、动作和空间参考缺口。例如涉及背身才检查背面依据，涉及握持才检查手与道具的关系。将必须支持的动作与可选美术展示分开。
- **示例：** 门口场景若只用正面中景，不因“资产完整”追加背面图；若已有分镜包含转身离开，则列出背面服装连续性的参考需求。
- **反例：** 只有一张正面图却声称背面细节已核实；不检查动作用途就要求生成整套表情。
- **检查：** 每项参考需求能对应具体动作或景别；现有素材是否足够与图像是否已确认分开；表达建议没有新增重要剧情。
- **传递：** 将需求写入 AST → SH 对应表；素材缺失只阻止相关视觉验收，不阻止其他文字分镜规划。
- **【待你确认 U05 / U08】** 对表情幅度、身体夸张和姿态可读性的偏好，以及哪些情况必须提供额外参考。

<a id="a03"></a>
## A03 · 场景空间、动线与道具状态

- **解决问题：** 单张场景图成立，但人物位置、出入口、镜头方向或道具去向无法前后对应。
- **适用：** 一场戏跨多个镜头，涉及移动、交接物件或空间遮挡。
- **不适用：** 把构图参考当成已核实的完整平面布局；无依据填入精确建筑尺寸；为铺场景而增加情节。
- **操作：** 标出原稿给出的出入口、主要区域、行动路径及关键道具。用简单文字关系或草图说明相对位置；记录道具在关键动作前后的持有人、位置、朝向及损坏状态。未知空间关系给出候选供当前项目选择。
- **示例：** 已知阿禾从走廊走到门口并放下风车，记录“人物到门口”“风车由手中转到门边”“人物离开”。门在画面哪一侧若未确定，作为镜头设计选项，不写成现场事实。
- **反例：** 相邻镜头中风车从门左侧跳到右侧却无动作解释；人物从未建立的出口突然离开。
- **检查：** 进入与离开可解释；关键位置和道具状态在相邻镜头中对应；设计假设、原稿事实及参考观察分开。
- **传递：** 场景与道具决定进入 AST 规格、V02 调度设计和片段接点检查；位置变化列出受影响 SH，而非重做全部场景。
- **【待你确认 U05 / U08】** 空间连续性的严格程度，哪些风格化跳跃允许，哪些关键物件必须逐镜保持。

<a id="a04"></a>
## A04 · 风格参考、用途与版本一致性

- **解决问题：** 参考很多却相互冲突，或下游引用了旧版素材。
- **适用：** 同时使用角色、场景、色彩、构图或材质参考，需要统一项目范围内的视觉方向。
- **不适用：** 从一张参考推导用户长期审美；默认复制参考中的人物、构图和所有细节；用未观察到的内容补全素材。
- **操作：** 项目视觉方向未定时，按已确认 U04 结合故事提供 2–3 种文字风格方案，说明效果与代价，由用户选择；已有明确风格直接复用。为每份参考注明用途与来源版本，例如只借色彩、不借造型。将“柔和”“克制”等词转成当前项目可比较的光线、轮廓、色彩关系或细节方案，不固定数值。遇到冲突先查已有决定，未决定时比较取舍。
- **示例：** 一张图用于角色外形，另一张图用于场景色调。若色调方案会让角色关键轮廓难以分辨，就给出调整环境明暗或保留角色明暗关系的方案，说明影响；不把第二张图中的人物替换进来。
- **反例：** 用户在一个夜景选了低对比处理，就把所有场景都改成同样的光线；把上传的候选图直接标成已接受版本。
- **检查：** 每个引用有明确用途和真实位置；不同参考冲突有处理依据；已确认版本与新候选分开；未实际看到的视觉效果不判通过。
- **传递：** 全片或场景级风格决定传到 AST、SH、提示词与 V05 检查；项目选择不自动更新个人方法库。
- **【待你确认 U04 / U05 / U08】** 希望参考遵循到什么程度，以及发生冲突时优先保留人物识别、环境氛围还是其他具体目标。
