# 需要你补充的内容

本表列出本 Skill 的默认规则（U01–U08）和可补充项，用于把通用方法逐步调整为你的个人方法。现在不需要全部填写，也不需要为填写本表先生成素材。已有项目、截图、前后版本或口头解释都可以作为整理依据。

固定边界：参考七阶段流程；只交付本地规划文档；不建数据库、不接入生成，不上传或发布。以下开放项不会改变这些边界，也不代表必须立即回答。

已起草三组通用方法：[故事与导演意图](story-and-direction.md)、[动画角色与场景资产](animation-assets.md)、[分镜与验收](storyboarding-and-review.md)。这些资料可以支持候选方案，不是你的已确认偏好，也没有真实项目效果验证。你无需先编写完整方法论；可以通过选择、批注和案例逐步校准，一次只确认一个当前关键问题。

**默认规则不是当前用户的确认。** U01–U08 由本 Skill 作者设定，随 Skill 分发；直接应用，不要求逐条确认，但不能写成“你已确认”。当前用户提出不同要求时，在其说明范围内优先并记为项目决定；用户明确要求作为长期偏好时，才修改本表。某次项目选择只作用于该项目或列明的场景，不能自动升级为默认规则。

本表用于定制 Skill，不是每个项目都要重填的问卷。

## 最小起步材料

先提供一个代表性项目即可，尽量包括原始需求、你认为满意的结果，以及三条满意原因和三条常见问题。有过程文档、提示词和失败结果则一并提供；缺少时如实说明，不必补造。

任何现有作品都不会自动成为你的默认风格。提炼后应由你确认哪些经验可跨项目复用，哪些只适用于该作品。

## U01 · 作品定位

**【默认规则 U01】** 本 Skill 作者设定的默认定位，不代表当前用户的确认；用户另有要求时在其项目范围内优先。

本 Skill 以**剧情类动画短片**为主要应用方向，将故事或剧本整理为**角色资产规划、场景资产规划和分镜方案**。当前仅交付规划文档，不接入生成。

- 核心工作：从故事或剧本到角色、场景资产与分镜方案的规划。
- 当前边界：不接入生成，不上传、不发布。
- 不适用：真人拍摄、广告或产品宣传片。
- 具体项目的用途和受众按需补充，不影响默认定位的应用。
- 本 Skill 的显示名称为“剧本到短片制作规划”。

<a id="u02"></a>
## U02 · 原稿与改写权限

**【默认规则 U02】** 已有故事或完整剧本采用有限润色边界；一句创意或简短大纲采用“保留已有设定，先补大纲，确认后再扩写剧本”。以下为默认规则，每个项目的明确要求可覆盖。

| 内容 | 当前状态 | 执行边界 |
| --- | --- | --- |
| 核心剧情、人物关系、结局 | 默认：保留 | 不借润色改变这些内容 |
| 对白 | 默认：允许润色 | 在保留核心剧情、人物关系和结局的前提下润色 |
| 动作、环境描写 | 默认：允许润色 | 润色不等于可以擅自增删重要情节 |
| 剧情结构调整、重要情节增删 | 默认：需要先取得用户确认 | 先提出建议，用户确认后再修改 |
| 旁白及其他未明确内容 | 未单独授权改写 | 保留原稿，具体项目明确要求时再按其处理 |
| 一句创意或简短大纲的扩写 | 默认：先大纲，确认后再扩写剧本 | 保留已有设定，先补出包含主要人物关系、关键情节和结局的大纲；补充内容标为提案，用户确认大纲后再扩写剧本 |

不重复确认已经允许的有限润色或大纲起草；仅对超出边界的修改提出具体建议并等待决定。简短创意的大纲须区分已有设定与新增提案；未经确认不进入剧本扩写。已有明确的大纲确认记录可直接沿用，不重复确认。

<a id="u03"></a>
## U03 · 叙事、分镜与节奏方法

**【默认规则 U03】** 按具体故事决定，不设统一偏好，每个项目结合故事比较方案。

叙事、分镜与节奏取舍按具体故事比较，不预设人物情绪或情节推进始终优先。按需使用 [S01–S04](story-and-direction.md) 与 [V01–V03](storyboarding-and-review.md)，结合本项目的事件、人物关系和表达目标说明方案效果与代价，一次只问一个关键问题。已明确的项目决定直接复用；某次选择只作用于列明的项目或场景，不自动成为跨项目偏好。通用方法仍是建议，不因本条默认规则而变为已接受的个人方法。

**【按需提供 · 项目参考】** 有案例时，任选能体现本项目判断的一种资料即可；没有案例不阻碍先提出方案：

- 原始故事与修改后的故事，说明改动为什么更好；
- 一段你认可的分镜，解释关键镜头为什么必须存在；
- 一段参考视频及具体时间点，说明节奏、信息揭示或情绪处理值得参考之处。

**可结合本项目讨论的判断：** 什么信息先给观众；何时停留、何时剪切；动作与反应怎么衔接；怎样处理对白；哪些镜头可以省掉；什么情况下需要留白。

没有案例时可先提出通用方案，但不把“固定反转频率”“固定镜头数”等未经验证的数值写成你的方法。

<a id="u04"></a>
## U04 · 视觉与镜头风格

**【默认规则 U04 · 方案选择方式】** 每个项目结合故事提供 2–3 种文字风格方案，说明效果与代价，由用户选择。

每个项目尚未指定视觉风格时，结合该故事提供 2–3 种有实际差异的文字风格方案，说明角色、场景或镜头中的具体表现、预期效果与代价，由用户选择。一次只问当前的风格选择问题；已指定或已确认的项目风格直接复用，不重复比选。方案选择后记录适用范围，并传递到相关资产与分镜；未选中的方案保持候选，不自动混用。

通用辅助条目：[S01 导演意图](story-and-direction.md#s01)、[A04 参考与一致性](animation-assets.md#a04)、[V01 镜头作用](storyboarding-and-review.md#v01)。当前只交付文字方案，不生成风格图。具体风格、参考用途和禁区仍按项目确定，本条不代表接受某种固定画风。

| 参考或规则 | 按项目需要填写 |
| --- | --- |
| 喜欢的参考 | 文件或链接，以及具体参考的是色彩、光线、构图、材质、表演还是镜头运动 |
| 不喜欢的参考 | 文件或链接，以及明确的问题 |
| 稳定偏好 | 可以跨项目使用的审美原则 |
| 项目可变项 | 根据题材调整的风格和镜头方式 |
| 禁止事项 | 例如不出现某类视觉元素；没有要求时留空 |

不默认采用任何特定导演的风格，不把形容词直接当作可验收指标。例如“克制”应结合一个具体镜头说明，而不是自动翻译成固定色数或固定运镜次数。

<a id="u05"></a>
## U05 · 资产方法与素材包

**【默认规则 U05 · 参考规划原则】** 按镜头需要，优先复用现有素材，只列必要的视角、表情、动作和空间参考。

默认先检查并复用现有适用素材，再按实际动作和镜头用途列出必要的参考缺口，不统一要求完整三视图、表情表或场景设定包。每项需求说明其支持的镜头或动作；缺少素材时先记录需求，不将规划写成已完成素材。

**【按需提供 · 项目素材】** 可以提供已有素材，无需为了本 Skill 重新制作。

[A01–A04](animation-assets.md) 已提供角色识别、动作参考、场景动线和参考一致性的通用方法。可据此起草文字规格；真正的素材检查仍需实际文件或可访问内容，不能用通用示例替代你的素材。

| 素材类型 | 按需要提供 | 需要你说明 |
| --- | --- | --- |
| 人物 | 能辨认身份的主参考；镜头需要时提供其他视角或细节 | 哪些身份特征必须稳定，允许哪些变化 |
| 场景 | 空间参考、主要出入口、关键物件位置；必要时附简图 | 哪些空间关系不可改变 |
| 道具 | 外形、大小或关键使用方式的参考 | 它如何参与剧情、状态如何变化 |
| 风格参考 | 图片或视频片段 | 参考什么，哪些内容不要模仿 |
| 声音与文字 | 已确定的对白、音乐、字幕、Logo 或品牌文字 | 是否必须原样保留，是否可以使用或修改 |

每份素材尽量注明：名称、文件或链接、来源、版本、用途，以及“已确认 / 候选 / 仅参考 / 旧版本”。素材使用权限不明时注明待核实，不自动上传或发布。

本条只设定参考规划原则；具体素材、设计与接受标准仍按项目记录，不因默认规则存在就把素材标为已接受。

## U06 · 提示词与实作经验

**【默认规则 U06 · 提示词交付规则】** 项目明确需要时才附上平台无关的提示词草案，并标明尚未验证。

仅在项目明确需要图片或视频提示词时附上相应草案；只做角色、场景资产或分镜规划时不自动附加。采用平台无关的文字描述，每份草案标明“尚未验证”；不写未经核实的平台专有语法、模型参数或调用命令，不提交生成。

**【按需提供 · 实作案例】** 有现成案例时可补充以下对照记录；没有案例不阻碍按上述规则起草：

[V04](storyboarding-and-review.md#v04) 仅提供图片与视频描述、引用匹配的通用方法；它不能代替真实的成功或失败结果。

| 提示词版本 | 输入参考 | 当时平台、模型与参数（如知道） | 对应实际结果 | 成功或失败的具体原因 | 后续修改与结果 |
| --- | --- | --- | --- | --- | --- |
| 待提供 | 待提供 | 不知道可写未知 | 待提供 | 待说明 | 没有可留空 |

我可以从对照案例提炼有效做法；只有一条提示词、没有结果时，只能参考写法，不能宣称效果已验证。旧模型经验不直接当作当前模型能力或费用依据。

## U07 · 视听规格与交付目标

**【默认规则 U07 · 时长规划规则】** 结合故事建议时长范围，说明节奏取舍，由用户确认后再细化时长规划。

项目未指定目标时长时，先结合故事的事件、对白、动作与情绪停留建议时长范围，说明节奏取舍；用户确认后再细化逐镜估时与片段时间分配。建议范围保持候选状态，确认前可继续不依赖目标时长的规划。已有明确目标时长或有效确认直接复用，不重复询问；估计仍须注明依据，不冒充实测。

**【默认规则 U07 · 文档组织方式】** 默认用一份项目工作表，按章节容纳本轮所需的剧本、资产、分镜等内容。

默认使用一份项目工作表，按章节组织本轮约定的剧本、资产、分镜及其他必要内容；只保留本轮所需章节，不为填满模板增加产物。项目已有明确文档组织要求时沿用；本条不要求合并、覆盖或搬移既有文件。

**【默认规则 U07 · 画幅选择规则】** 结合观看用途与故事提出画幅建议，说明构图影响，由用户选择。

项目未指定画幅比例时，结合观看用途与故事提出画幅建议，说明对人物安排、空间呈现及观看重点的构图影响，由用户选择；已有明确画幅直接复用，不重复询问。用途未知且影响判断时只询问当前关键缺口，不擅自假定发布平台。未选择时画幅及相关构图保持候选，其他不依赖画幅的规划可继续；选定比例记录为项目决定并传到相关资产规格与分镜。

**【默认规则 U07 · 声音与字幕规划规则】** 结合故事提出声音与字幕的用途建议，标为待确认，由用户选择后纳入方案。

原稿未明确声音或字幕时，结合故事提出相应用途建议，说明服务于哪些信息、情绪或观看需求，标为待确认；用户选择后再纳入相关分镜或按需交付的提示词方案。已有明确要求直接沿用；未选中的建议不自动混入方案。原稿对白、旁白及其他文字仍遵守 U02，选择用途不自动授予改写原文或增删重要剧情的权限。当前只写文字规划，不生成声音、字幕媒体或视频。

**【按需提供 · 其他项目规格】** 本 Skill 的执行终点固定为规划文档；具体时长、画幅、声音与字幕按上述规则确定，未来媒体交付规格仍按项目确定。

- 作品用途、观看平台与目标时长：
- 画幅比例及未来需要的导出规格：
- 对白、旁白、音乐、音效和字幕：哪些需要、哪些禁止、哪些尚未决定：
- 未来希望收到哪些产物：分段素材 / 成片 / 可编辑工程 / 其他：
- 需要保留哪些中间资料：

未确定的时长与技术规格保留待定。未来需要可编辑工程时，还需明确剪辑软件与版本；当前不据此安装或调用工具。

## U08 · 验收标准

**【默认规则 U08 · 集中验收方式】** 先检查一致性，再将本轮约定的文档、问题与待定项集中提交，由用户验收；大纲、风格和时长等确认点继续保留。

先按本轮范围和已确认项目决定检查文档一致性，再将约定的文档、检查结果、问题与待定项集中提交，由用户验收。集中提交不替代或推迟 U02 的大纲确认、U04 的风格选择及 U07 的时长、画幅、声音与字幕选择；相关依赖工作仍在对应确认后展开，不额外要求每个阶段都单独验收。文档已交付、检查已完成与用户已接受分别记录；只有用户明确接受的版本和范围才标为已验收。

默认规则只规定提交与验收方式；下面提供的是检查维度，尚不是你的验收标准，具体标准用【待你确认 U08】按项目补充。[V05](storyboarding-and-review.md#v05) 已给出通用的分层检查方法，各方法条目也有针对性检查点。可以先检查事实并给出问题，不因个人标准尚未填完而暂停所有工作；“已检查”不等于“你满意”。

| 产物 | 可先检查的事实 | 【待你决定 U08】 | 所需证据或检查方式 |
| --- | --- | --- | --- |
| 剧本 | 必留内容是否有对应，新增改动是否标出 | 叙事是否成立、情绪是否到位、哪些改动可接受 | 原稿对照、你的批注 |
| 资产 | 文件是否存在，身份锚点和版本是否清楚 | 外形、风格与细节允许偏差的范围 | 实际图片并排检查、你的接受记录 |
| 分镜 | 原文覆盖、时长估计、动作顺序与空间关系是否自洽 | 镜头作用、信息密度与节奏是否合适 | 分镜对照、试读或后续预演；未做则标未测 |
| 提示词 | 输入、动作、镜头、声音和约束是否冲突 | 是否准确表达你想要的画面 | 文本审阅；生成效果需未来实际结果支持 |
| 分段视频（未来） | 实际时长、人物、动作、声音与接点 | 哪些瑕疵可接受，哪些必须重做 | 实际逐段播放，不以缩略图代替 |
