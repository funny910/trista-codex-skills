# 方法库一：故事与导演意图

**【通用方法草案 v0.1】** 用于提出可讨论方案，尚未确认为用户的个人方法，未经真实项目效果验证。示例均为虚构，不可当作用户剧情或授权。每次只读取当前问题需要的条目。

项目中的选择只作用于列明范围；成为长期默认方法需用户另外明确确认。下列“待确认”项按需一次讨论一个，不构成整库使用前的审批清单。已有原稿遵守 U02 有限润色边界；一句创意或简短大纲保留已有设定，先补出主要人物关系、关键情节和结局，经用户确认大纲后再扩写剧本。

已确认 U03：按具体故事比较叙事方案，不设统一偏好。下列涉及 U03 的问题仅在项目中按需讨论，已明确的项目取舍直接复用。

<a id="s01"></a>
## S01 · 从核心事件形成导演意图

- **解决问题：** 剧情已经存在，但不清楚观众应关注什么、感受到什么。
- **适用：** 一场戏或一段故事有可识别事件，需要统一角色、场景与镜头的表达重点。
- **不适用：** 用户只要格式整理；或尚无可识别事件，需要先按 U02 起草大纲。不要通过“导演意图”擅自改主题或结局。
- **操作：** 先概括已给事件及人物目标；区分故事事实与表达建议；提出一个可观察的叙事重点、一个情绪目标，以及支撑它的动作、空间或声音处理。用户已有明确方向时直接复用。
- **示例：** 已知“阿禾放下修好的纸风车后离开”。候选意图是让观众关注“想接近又保持距离”，可用已写出的停顿和人物与门的距离表达，先标为建议。
- **反例：** 只写“表现复杂内心、营造电影感”，没有画面依据；或凭空增加朋友出门和解，以为这样更感人。
- **检查：** 意图能对应已有事件；具体表达能在画面或声音中辨认；没有把推测的心理和关系写成事实。
- **传递：** 确认后的目标写入场景或全片决定；角色表演参考、场景空间重点、SH 的叙事作用按该范围检查。
- **【待你确认 U03 / U04】** 哪些情绪表达与你的偏好相符；更喜欢明确表达还是保留理解空间。未确认前均提供为选项，不设全局默认。

<a id="s02"></a>
## S02 · 信息分配与开场选择

- **解决问题：** 观众该何时看到某个已存在的信息，开场怎样建立理解与兴趣。
- **适用：** 原稿已有事件和关键线索，存在不同视角或观看重点可选。
- **不适用：** 为制造悬念而添加新威胁、反转或人物秘密；删除必须保留的线索；已经明确指定观看顺序的项目。
- **操作：** 列出观众当前知道、角色知道、需要后续交代的信息；围绕同一事件比较“先建立环境与行动”“先关注已存在的关键物件”等表达。说明是否改变叙事顺序或关键情节；如有改变，按 U02 先提建议等待确认。
- **示例：** 同一放下风车的动作，可以先让观众看清人物与门的位置，也可以以风车的修补痕迹作为观看重点；后者需要补足空间信息，且修补痕迹本身必须有原稿或获准设计依据。
- **反例：** 用户写的是普通送还物件，方案却新增追逐或倒计时；为了“反转密度”强行打乱事件。
- **检查：** 每条关键信息都有落点；保留原定结局；若理解需要推断，说明可能的理解成本。没有固定开头长度、反转频率或套路配额。
- **传递：** 将确认的信息揭示点记录到 SRC 与 SH 对应处，必要的物件细节进入 AST 需求；不把一次开场选择套到所有场次。
- **【项目判断 U03】** 结合当前故事比较清楚跟随事件或适度保留信息的效果与代价，不设跨项目默认。

<a id="s03"></a>
## S03 · 用可见行为与对白配合表达

- **解决问题：** 情绪只存在于抽象说明，人物行为或对白缺乏明确作用。
- **适用：** 已有原稿允许有限润色，需要提高动作、对白的可理解性，或为表演参考提供依据。
- **不适用：** 更改角色关系、动机结论或核心行动；用户明确要求逐字保留的对白和未获准改写的旁白。
- **操作：** 找出原稿已经给出的动作与对白，明确它们的对象、顺序和结果；将模糊动作写得可观察。新增表演细节列为建议，检查是否改变事实或重要情节；必要时比较保留人物互动与关注动作细节两种表达。
- **示例：** 原稿已有“伸手，停顿，再离开”，可在分镜中说明手停在何处、停顿发生在动作哪个环节。这个位置若原稿未定，标为表演建议，而不是假装原文已有。
- **反例：** 用“她终于原谅了他”充当画面描述；或把一句润色改成与原意相反的对白。
- **检查：** 可见动作与原稿核心事件一致；对白没有改变关系或承诺；无法直接看到的心理只用于解释建议，不冒充画面。
- **传递：** 确认的表演细节进入 SH 和 A02 参考需求；对白版本与所据 SRC 对应，后续估时使用同一版本。
- **【待你确认 U03 / U08】** 喜欢怎样的对白自然度、停顿和表演强度；需要哪些失败案例来校准“过度”与“不足”。

<a id="s04"></a>
## S04 · 因果、覆盖与节奏检查

- **解决问题：** 内容没有遗漏却显得跳跃、拖沓，或情节密度与情绪重点不匹配。
- **适用：** 有概要、完整剧本或分镜可对照，正在检查事件之间如何连接。
- **不适用：** 以通用节拍模板代替用户已有结构；把节奏问题自动等同于删减情节；凭未计时文本承诺成片时长。
- **操作：** 为每场记录起始状态、关键行动、变化结果及与下一场的联系；检查重点信息是否覆盖。分别看事件推进与情绪停留，再提出延长观看、重新组织镜头或结构调整的不同建议；涉及结构或重要情节的改动先取得确认。
- **示例：** 从“拿着风车走近门”直接跳到“空走廊”可能缺少观众理解所需的放下动作，应先核对是否原稿已有而分镜漏掉，再修正覆盖；不能直接增加新的离别事件。
- **反例：** 每隔固定秒数必须反转；每场都要求同样数量镜头；把旁白字数直接当作实测时长。
- **检查：** 关键事件有对应位置；因果断点与审美偏好分开报告；时间估计标明依据；修复遵守 U02。
- **传递：** 内容覆盖问题回到 SRC / SH；时长问题交给 V03；需要用户选择的节奏方向形成场景级决定。
- **【待你确认 U03 / U08】** 哪些节奏实例是你认为合格、太慢或太密的参照；没有实例时只给诊断建议，不宣布审美合格。
